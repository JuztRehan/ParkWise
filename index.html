About this project

This portable edition works without a server or internet. It saves records in this browser using IndexedDB and displays your phone’s local time. Each phone has its own separate parking records. The original desktop project uses Flask and SQLite.

This is an offline demonstration without login. Records are not shared between phones. CSV export provides a readable copy of your history. Future IoT integration could accept authenticated sensor events and reconcile them with operator tickets. No real payment collection or hardware integration is performed here.
